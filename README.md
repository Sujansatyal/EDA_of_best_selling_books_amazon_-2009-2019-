# 📊 Amazon Bestselling Books EDA
📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a dataset of Amazon bestselling books to uncover patterns, trends, and insights related to book performance, pricing, user ratings, and reader engagement.

The goal of this analysis is to understand what factors contribute to a book becoming a bestseller and how different attributes such as genre, price, and reviews influence popularity.

---

## 📂 Dataset Description

The dataset contains information about bestselling books, including:

* **Name** – Title of the book
* **Author** – Author of the book
* **User Rating** – Average rating given by users
* **Reviews** – Number of user reviews
* **Price** – Price of the book
* **Year** – Year of bestseller listing
* **Genre** – Fiction / Non-Fiction

---

## 🔍 Key Analysis Performed

### 🔹 Univariate Analysis

* Distribution of ratings, reviews, and prices
* Genre frequency analysis
* Identification of outliers and skewness

### 🔹 Bivariate Analysis

* Relationship between reviews, ratings, and price
* Genre-wise comparison of reviews and ratings
* Year-wise trends in book popularity

### 🔹 Multivariate Analysis

* Combined analysis of genre, year, and reviews
* Correlation heatmap of numerical features
* Identification of patterns across multiple variables

---

## 📈 Key Insights

* Most bestselling books have **high user ratings (above 4.5)**
* The distribution of reviews is **highly skewed**, with a few books receiving extremely high attention
* **Non-Fiction books slightly dominate** the dataset
* Book prices are generally consistent and **do not strongly influence popularity**
* There is **no strong correlation** between price, ratings, and number of reviews

---

## 🛠️ Tools & Technologies

* Python 🐍
* Pandas

---

## 🎯 Conclusion

The analysis indicates that **book success is primarily driven by reader interest and content appeal rather than price or rating alone**. A small number of highly popular books significantly influence overall trends in the dataset.
